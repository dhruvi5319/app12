Create Playwright test infrastructure so Plan 02 can add E2E tests.

**package.json** — minimal, Playwright only:
```json
{
  "name": "task-tracker",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "test": "playwright test",
    "serve": "npx serve . -l 3000"
  },
  "devDependencies": {
    "@playwright/test": "^1.44.0"
  }
}
```

**Install Playwright:**
```bash
npm install
npx playwright install chromium --with-deps
```

**playwright.config.js** — configure for local file serving:
```js
const { defineConfig } = require('@playwright/test');

module.exports = defineConfig({
  testDir: './e2e',
  timeout: 10000,
  use: {
    baseURL: 'http://localhost:3000',
  },
  webServer: {
    command: 'npx serve . -l 3000 --no-clipboard',
    url: 'http://localhost:3000',
    reuseExistingServer: !process.env.CI,
    timeout: 10000,
  },
});
```

Create `e2e/` directory placeholder (will hold tests from Plan 02):
```bash
mkdir -p e2e
```
